## 9. First 90-Day Build Plan

### Days 1–15

- Finalize MVP requirements
- Design database schema
- Design dashboard UI
- Build landing page
- Start operator interviews

### Days 16–45

- Build auth, organizations, tours, availability
- Build booking widget
- Build Stripe payment flow
- Build basic guest CRM

### Days 46–70

- Build email/reminder automation
- Build waiver system
- Build guide manifest
- Build basic reports

### Days 71–90

- Build AI Growth Dashboard v1
- Launch beta onboarding
- Fix real user issues
- Prepare case studies

## 10. Critical Mistakes to Avoid

- [ ] Building too many AI features before booking works
- [ ] Ignoring payment/compliance basics
- [ ] Competing only as a cheap booking tool
- [ ] Overcomplicating UI for solo operators
- [ ] Depending on OTA integrations too early
- [ ] Claiming AI can do things it cannot safely do
- [ ] Using dynamic pricing without operator control
- [ ] Skipping migration support
