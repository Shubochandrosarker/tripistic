# Tripistic MVP Roadmap

## Phase 0 — Positioning & Validation

Goal: Validate the pain, message, and pricing before building too much.

### Tasks

- Create landing page
- Publish pricing promise: 0% direct-booking commission
- Create waitlist
- Interview 20–30 operators
- Build demo screens
- Test offers in Facebook/Reddit/operator communities
- Collect first beta users

### Validation Questions

- Are operators angry about booking fees?
- Do small operators understand “AI Growth Dashboard”?
- Will solo guides pay $19–$29/month?
- Will operators switch for 0% direct commission?
- What integrations are non-negotiable?

## Phase 1 — MVP Backbone

Goal: Build enough operational system to handle real bookings.

### Must-Have Features

- Business onboarding
- Tour/product setup
- Availability calendar
- Booking widget
- Stripe payments
- Deposit support
- Guest CRM
- Email confirmation
- Basic SMS/WhatsApp reminders
- Digital waiver link
- Guide manifest
- Admin dashboard
- Basic reports

### MVP AI Feature

Ship only one strong AI module first:

> AI Growth Dashboard

Initial version can use rules + simple analysis + LLM explanation.

Example insights:

- “Your Saturday morning tour has 72% higher occupancy than weekdays.”
- “Your Thursday tour is underbooked. Try a 10% weekday promo.”
- “Direct bookings are only 28%. Add the booking widget above the fold.”
- “You had 12 waiver reminder failures last month. Send reminders 24 hours earlier.”

## Phase 2 — Paid Beta

Goal: Get the first 20–50 paying operators.

### Beta Offer

- $19/month solo beta
- $69/month operator beta
- Free migration help
- No long-term contract
- Founder-led onboarding

### Beta Metrics

Track:

- Number of active operators
- Booking volume
- Direct-booking percentage
- AI insight usage
- Churn reasons
- Support tickets
- Failed bookings
- Payment success rate

## Phase 3 — AI Expansion

Goal: Add high-differentiation AI features after the booking backbone works.

### Add Features

- Multilingual AI booking agent
- AI itinerary builder
- Demand forecasting
- No-show prediction
- AI review response drafts
- AI content generator
- Transparent dynamic pricing suggestions

## Phase 4 — Channel & Integrations

Goal: Make Tripistic usable for operators already selling across OTAs.

### Priority Integrations

1. Viator
2. GetYourGuide
3. Google Things To Do
4. Google Calendar
5. QuickBooks/Xero
6. Zapier/Make
7. WhatsApp Business API

## Phase 5 — Scale & Moat

Goal: Turn Tripistic into a defensible SaaS platform.

### Moats

- Historical booking data
- AI growth recommendations
- Operator benchmarking
- OTA-to-direct conversion insights
- Agent-commerce readiness
- White-label agency layer
- Marketplace/add-ons

## Success Thresholds

Do not over-expand before these are true:

| Stage | Threshold |
|---|---|
| MVP validation | 20+ serious beta leads |
| Paid beta | 20+ paying operators |
| Product-market signal | 100+ paying operators |
| Retention health | Less than 5% monthly churn |
| AI proof | Measurable booking/revenue/no-show improvement |

## Build Warning

Do not build every AI feature at the start.

The correct sequence is:

1. Booking backbone
2. Payment + communication
3. AI Growth Dashboard
4. Booking agent
5. Forecasting/dynamic pricing
6. Itinerary builder
7. Marketplace/agent-commerce
